V1 model
functioning: 
user uploads a research paper -> grobid extracts the metadata & saves in SQlite 
user queries specifically about metadata -> NLP to SQL generation -> SQL querying on sqlite db -> result generation -> llm creates final response.

nlp to sql:
Prompt with:
DB schema
Allowed tables
Instructions: "Return ONLY valid SQL."
Restrict to SELECT queries only
Reject DDL / DML statements
Validate SQL before execution

Important detail:
0.0.0.0 → accepts requests from any network interface
If you use 127.0.0.1, only local machine can access it
